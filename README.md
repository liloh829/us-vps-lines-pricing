## 线路：美国VPS差价的主要来源

一句话答案：线路决定晚高峰还能不能用，这比CPU多一核少一核重要得多。

美国机房离国内物理距离摆在那里，数据要先走国际出口再进国内骨干网，走哪条线路，体验天差地别。电信方向常见的承载网络有三种，联通方向另有一种：

| 线路 | 路由特征 | 实际体验 |
| --- | --- | --- |
| 传统163骨干（AS4134） | 全程走202.97节点，无优化 | 用的人最多，晚高峰卡顿、丢包明显 |
| CN2 GT | 202.97和59.43混走，只在国际出口段走CN2 | 比163好一档，但晚高峰同样会拥堵 |
| CN2 GIA | 去程回程全程走59.43高速节点 | 稳定、快、丢包低，价格也最高 |
| 联通9929（AS9929） | 联通A网 | 质量堪比电信CN2 GIA |

两个实用判断。商家页面没有特殊标注线路的，默认就是163骨干，便宜套餐基本都归这类。宣传里只写“CN2”两个字母的，多半是GT——真有GIA，商家一定会写全称，而且GIA方案的价格不会便宜到年付几十美元，看到"CN2 GIA"配个低价，先留个心眼。

联通用户可以单独看AS9929，目前的表现不输CN2 GIA，价格往往还便宜些。
